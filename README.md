## SaaS / Hosted Platforms

| Platform | Pricing | Free Tier / Limits | Key Highlights |
| :--- | :--- | :--- | :--- |
| **[Shopify](https://www.shopify.com/)** | Basic: $39/mo, Shopify: $105/mo, Advanced: $399/mo, Plus: from $2,300/mo | 3-day free trial; then $1/mo for first month. No permanent free tier. | Leading all-in-one hosted commerce engine with massive app marketplace, payment gateways, and checkout customization. |
| **[BigCommerce](https://www.bigcommerce.com/)** | Standard: $39/mo, Plus: $105/mo, Pro: $399/mo, Enterprise: Custom | 15-day free trial. No permanent free tier. (Sales volume limits apply per tier). | Enterprise-ready SaaS platform with built-in multi-storefront capabilities, zero transaction fees, and headless API options. |
| **[Wix eCommerce](https://www.wix.com/ecommerce)** | Core: $29/mo, Business: $36/mo, Business Elite: $159/mo | Free tier available for building site, but accept online payments requires paid plan. | Visual drag-and-drop website builder with integrated checkout and product catalog for SMBs. |
| **[Squarespace Commerce](https://www.squarespace.com/)** | Business: $23/mo (3% fee), Commerce Basic: $28/mo (0% fee), Commerce Advanced: $52/mo | 14-day free trial. No permanent free tier for selling products. | Design-first website builder with integrated commerce, subscriptions, and digital content delivery. |
| **[Salesforce Commerce Cloud](https://www.salesforce.com/products/commerce-cloud/)** | Gross Merchandise Value (GMV) based pricing / Enterprise quote | No free tier. Demo/sandbox access by request. | Enterprise cloud commerce solution tailored for global B2B and B2C brands with AI integration. |
| **[Adobe Commerce (Magento SaaS / Cloud)](https://business.adobe.com/products/magento/magento-commerce.html)** | Custom based on GMV and average order value | No free tier. Demo upon request. | Cloud-hosted version of Magento offering enterprise staging, cloud infrastructure, and B2B workflows. |

## Open-Source & Self-Hosted Platforms

| Platform | Tech Stack | License | Description |
| :--- | :--- | :--- | :--- |
| **[WooCommerce](https://github.com/woocommerce/woocommerce)** | PHP / WordPress | GPL-3.0 | The world's most widely used open-source e-commerce solution built on WordPress. |
| **[PrestaShop](https://github.com/PrestaShop/PrestaShop)** | PHP / Symfony | OSL-3.0 | Fully featured, customizable open-source e-commerce web platform for merchants and developers. |
| **[OpenCart](https://github.com/opencart/opencart)** | PHP | GPL-3.0 | Lightweight and easy-to-run turn-key open source shopping cart system. |
| **[Shopware](https://github.com/shopware/shopware)** | PHP / Symfony / Vue.js | MIT | Trendsetting modular open-source e-commerce platform powering thousands of European and global shops. |
| **[Magento Open Source](https://github.com/magento/magento2)** | PHP / Zend / Laminas | OSL-3.0 | Flexible, feature-packed e-commerce application capable of scaling to massive catalogs. |
| **[Spree Commerce](https://github.com/spree/spree)** | Ruby on Rails | BSD-3-Clause | Modular, headless-ready open source e-commerce platform built for high-scale enterprise and multi-vendor marketplaces. |
